| Use Case                                          | Description                                                                                                                  | Preferred Model                                                 | Why                                                                                                                                                                                                        |
| ------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Behavior Regression Testing (CI)**              | Validate that a modified agent still performs the same logical task correctly.                                               | **Artifact Graph**                                              | Alternative execution strategies should pass as long as required artifacts, dependencies and outcomes are preserved.                                                                                       |
| **Reference Implementation Regression**           | Ensure an agent continues following a specific implementation strategy.                                                      | **Strict Trajectory**                                           | Every important tool invocation and ordering is intentional and should remain stable.                                                                                                                      |
| **Runtime Agent Validation (Evals / Guardrails)** | Validate every production execution against expected behavior and detect behavioral drift or policy violations in real time. | **Hybrid (Artifact Graph + Strict Trajectory)**                 | Correctness should be validated using behavioral invariants, while execution-specific anomalies (loops, excessive retries, forbidden tools, unexpected execution paths) require trajectory-level analysis. |
| **Open Source Benchmark / Leaderboard**           | Compare multiple agents solving the same task.                                                                               | **Artifact Graph**                                              | Different frameworks and tools should be comparable at the behavioral level.                                                                                                                               |
| **Agent Refactoring**                             | Verify that internal code changes did not alter behavior.                                                                    | **Artifact Graph**                                              | Refactoring should not require regenerating the contract.                                                                                                                                                  |
| **Prompt Regression Testing**                     | Detect behavioral changes after prompt modifications.                                                                        | **Artifact Graph**                                              | Prompt wording may change execution details while preserving intended behavior.                                                                                                                            |
| **Tool Migration**                                | Migrate from one tool implementation to another (e.g. `find` → `grep`).                                                      | **Artifact Graph**                                              | Tool choice changes, required behavior does not.                                                                                                                                                           |
| **Framework Migration**                           | Compare implementations across LangGraph, OpenAI Agents SDK, OpenClaw, Hermes, etc.                                          | **Artifact Graph**                                              | Tool names and execution models differ while workflows remain equivalent.                                                                                                                                  |
| **Production Monitoring**                         | Validate live executions against expected behavior.                                                                          | **Artifact Graph**                                              | Production agents naturally exhibit execution variability.                                                                                                                                                 |
| **Execution Optimization**                        | Detect redundant work, loops and unnecessary actions.                                                                        | **Strict Trajectory**                                           | Requires preserving the exact sequence of executed operations.                                                                                                                                             |
| **Performance Analysis**                          | Measure retries, duplicate tool calls, token growth, latency and execution efficiency.                                       | **Strict Trajectory**                                           | Optimization depends on the actual execution path, not only the final behavior.                                                                                                                            |
| **Trajectory Documentation**                      | Generate documentation explaining how the reference execution worked.                                                        | **Strict Trajectory**                                           | The purpose is to describe the observed execution rather than generalize it.                                                                                                                               |
| **Agent Debugging**                               | Explain why an execution failed or diverged.                                                                                 | **Strict Trajectory**                                           | The exact sequence of decisions and tool invocations is important.                                                                                                                                         |
| **Security / Compliance**                         | Verify that prohibited tools or operations were not executed.                                                                | **Strict Trajectory**                                           | Compliance often depends on exact actions, not only outcomes.                                                                                                                                              |
| **Behavior Mining**                               | Infer reusable behavioral specifications from successful trajectories.                                                       | **Artifact Graph**                                              | The objective is to extract reusable invariants rather than replay executions.                                                                                                                             |
| **Automatic Test Generation**                     | Generate regression tests from a successful execution.                                                                       | **Artifact Graph** (primary) + **Strict Trajectory** (optional) | Functional tests should validate behavior, while optional strict assertions can enforce implementation details when desired.                                                                               |
